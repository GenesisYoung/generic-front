# Generic ERP Frontend — app

This folder is the Vue 3 application. All `npm` commands run here.

- Overview and quick start: [../README.md](../README.md)
- Architecture, local development, conventions: [../DEVELOPMENT.md](../DEVELOPMENT.md)

```bash
npm install
npm run dev          # http://localhost:5173 (needs app/.env.local, see ../DEVELOPMENT.md)
npx vitest run       # unit tests
npm run build        # type-check + production build to dist/
```
